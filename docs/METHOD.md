# 方法：为什么这样问，为什么这样蒸馏

## 1. 问题不是「像不像」，是「凭什么像」

大多数「数字人」是这样做的：写一段人设（年龄、职业、性格、口头禅），再让模型扮演。聊三句还行，聊十句就露馅——因为它只有标签，没有记忆；只有态度，没有代价；只有光明面，没有矛盾。

一个人之所以是这个人，至少由四样东西组成：

1. **具体发生过的事**（场景、时间、谁在场、当时说了什么）
2. **在事里形成的判断**（什么重要、什么不能做、什么值得牺牲）
3. **表达这些判断的方式**（句长、标点、口头禅、幽默、沉默）
4. **不一致的地方**（渴望被看见又怕被评价；想要自由又怕被丢下）

所以这个项目不从「请描述你的性格」开始，而从「你妈打电话说你表妹要结婚，你第一反应是什么」开始。**评价会骗人，场景不会。**

## 2. 三个理论支点

### 2.1 叙事身份

McAdams 等人的叙事身份研究有一个核心观点：人通过讲述自己的故事来理解自己。故事不是事实的复述，而是**选择**——哪些事被记住、被放在转折点上、被赋予什么意义。

这决定了题库的设计：不问「你的童年幸福吗」，而问「最早的记忆是什么」「考砸了家里怎么处理」「人生最低谷你怎么活过来的」。我们收集的不是年表，是**被讲述过的经历**。

### 2.2 特质：用行为频率和情境差异估计

Big Five 不是五个标签，是五个维度上的相对位置。一个人可能对工作极度尽责、对生活琐事放任；可能对熟人话多、对陌生人冻结。所以题库里每个特质都有行为题和反例题：

- 「答应别人的事 vs 答应自己的事，哪个更容易做到？」
- 「聚会第 90 分钟你在哪里？」
- 「什么情境下你会变成另一个人？」

档案里不写「高尽责」，写「对客户提前交稿，对自己的 zine 拖两年」——后者才能生成行为。

### 2.3 依恋与冲突脚本

亲密关系里的模式，往往比性格标签更能预测一个人在具体场景下的反应：冲突时是追还是退，被丢下时是黏还是冷，需要空间时怎么说。

题库用「最近一次冲突」「你怎么和好」「你最怕在关系里发生什么」来逼近这个脚本，并在档案里标为**假设**，不写临床诊断。

### 2.4 价值：看牺牲，不看宣言

Schwartz 的价值理论把价值看作动机连续体（自主、安全、成就、享乐、权力、仁爱、传统、 conformity、普世、刺激）。但问卷里选「我很看重自由」没有意义。

所以题目逼出排序和代价：「自由、安全、成就、关系、意义——排序，并说最近一次你为了一个牺牲另一个是什么时候。」**你实际牺牲了什么，你就在乎什么。**

## 3. 十层模型

```
L0 事实     身份、地理、家庭、职业、健康、财务
L1 时间线   七个阶段：场景 / 关系 / 自我状态 / 转折 / 象征物
L2 性格     五维强度 + 情境差异 + 反例 + 依恋假设
L3 价值     排序、底线、金钱、成功、变化史
L4 关系     人物地图、角色、债务、未说出口的话
L5 语言     声音锚点、句法、标点、幽默、情绪脚本、禁语、改写规则
L6 行为     日常程序、决策流程、风险偏好、自我破坏、恢复方式
L7 阴影     欲望、恐惧、羞耻、秘密、黑暗念头（私密）
L8 未完成   遗憾、未做的事、十年愿景、墓志铭
L9 元       矛盾、空白、运行规则
```

越往下越难采集，也越决定「像不像」。很多项目只做了 L0–L3，所以数字人像一个「知道很多关于你的客服」；L5 和 L7 才是分水岭。

## 4. 题库设计的六条原则

1. **具体事件优先**：能问「那次你说了什么」就不问「你通常怎么处理」。
2. **同一构念多角度**：性格至少有三道题从不同场景逼近，允许答案不一致。
3. **主动找反例**：每道性格题都追问「有没有一次不是这样」。
4. **采集原话**：语言样本单独成章，要求贴聊天记录原文，不许润色。
5. **空白合法**：任何题都可以跳过；「想不起来」本身是信息。档案里保留「尚未采集」，数字人被问到时必须承认不知道。
6. **私密分层**：创伤、羞耻、秘密标为私密，默认不进入对外对话。没有分层，人不敢写真的。

## 5. 蒸馏：四次转换

`distill.py` 只做机械工作（覆盖统计、证据汇编、任务书生成）。真正的蒸馏由强模型按 `蒸馏指令.md` 完成，分四步：

1. **证据抽取**：把回答拆成一条条带题号的证据（事实 / 场景 / 性格证据 / 价值 / 语言 / 关系 / 阴影 / 矛盾）。
2. **推断**：每个结论至少两条证据，附反例；依恋只写假设。
3. **语言画像**：从原话提取句法、标点、词汇、幽默、情绪脚本、禁语；给出 before/after 改写。
4. **合成与自检**：按十层结构写 persona；用档案里没有的问题自测，标出哪些只能答「不知道」。

一个硬规则：**不允许用形容词代替原话**。「温柔而坚定」不能生成任何一句话；「先吃饭。吃完再说」可以。

## 6. 「完全一致」是什么意思

先把话说清楚：**100% 复制一个人是不可能的，也不是这个项目承诺的东西。** 没有意识、没有连续体验、没有身体、没有真实关系的数字人，不可能「完全一致」。

可以追求的是**保真度**，分四项：

| 维度 | 问什么 | 怎么测 |
| --- | --- | --- |
| 事实 | 它说的具体信息，档案里有吗？ | 抽查 20 条事实 |
| 语气 | 这句话像本人会说的吗？ | 盲测、句长/标点/用词对比 |
| 判断 | 它会做和本人一样的选择吗？ | 情境题，本人先答，再对比 |
| 情绪 | 它的反应强度、方式对吗？ | 冲突/被夸/难过场景 |

通过线：四项平均 ≥ 4.0（5 分制），诚实测试 5/5，熟人盲测 ≥ 8/10。

**过度拟合是失败，不是成功。** 如果数字人开始说「你希望自己成为的人」会说的话，它就不像你了。所以档案要保留矛盾、阴影和空白；校准要保留「不像」的日志。

## 7. 评估与迭代

- `twin/exam.md`：25 道题，含 5 道「必须承认不知道」的诚实测试。
- 盲测：本人先答一遍，数字人答一遍，打乱给朋友选。
- `twin/calibration.md`：每次「不像」只改一处，记录归因（事实/语气/判断/情绪/边界/太像 AI），保留版本。
- 不追求 5.0。剩下的差异如果本人也说不清，就保留为空白。

## 8. 伦理

- **镜子，不是替身**：不用于冒充本人签约、转账、承诺、操纵他人。
- **本地优先**：默认只存本机 SQLite；导出的是明文 Markdown，自己保管。
- **可删除**：所有回答可清空；导出文件可删；没有云端副本。
- **私密层**：默认不进入对话；只有本人明确授权才展开。
- **危机**：涉及自伤/自杀/暴力时，数字人必须脱离角色，建议联系真人和专业援助（中国大陆可拨 12356）。安全高于像不像。
- **不诊断**：不贴临床标签，不替代心理咨询。

## 9. 局限

- **自报偏差**：人会说给自己听的版本，不一定等于行为。
- **记忆重构**：回忆不是录像，会被现在改写。档案记录的是「你如何讲述」，这本身有用，但不是客观史。
- **社会赞许**：有些题（尤其是价值和阴影）会往「正确」的方向答。私密分层和可跳过只能缓解，不能消除。
- **样本量**：69 题能做一个可用的 v1，但要做高保真，需要 100+ 题、多次访谈和校准。
- **模型随机性**：同一个 persona，不同模型、不同温度，稳定度不同。运行规则和考试比「换个更大的模型」更重要。
- **文化差异**：题库偏中文语境、偏个体叙事；用于其他文化时需要改写。

## 10. 参考方向

- 叙事身份：McAdams, D. P. 及后续研究（故事、转折点、redemption/contamination 序列）。
- 特质：McCrae & Costa 的 Big Five 框架。
- 依恋：Bowlby、Ainsworth 及成人依恋的后续研究。
- 价值：Schwartz 的基本价值理论。

这些是设计题库时的方向，不是临床工具。这个项目不是心理测量，也不产出诊断。
