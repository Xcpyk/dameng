导出

导出这一次的档案

生成《人生档案》《蒸馏指令》《覆盖报告》和原始备份。把它们交给一个强模型，就能得到第一版数字人。

默认导出会隐去私密题的回答；勾选后会写入原文，请勿分享。

如何使用

这不是考试

这是一次有结构的口述史。先写记得的，空白和「想不起来」本身也是信息。

    三个建议

    分 4–8 次做，每次 30–60 分钟。不要在深夜一次答完。

    写具体的事，少写对自己的评价。「我比较内向」不如「聚会到 90 分钟我会去阳台」。

    标注「可跳过」的题涉及隐私，跳过不影响档案成立；想写时，可以只写你愿意写的部分。

    答案去哪了

    只写进本机的 data/dream.db，页面不联网。导出后生成的 Markdown 也只在项目目录里。

    导入回答备份

    选择网页或插件导出的《回答备份.json》，只补充尚未回答的题；已有答案不会被覆盖。
